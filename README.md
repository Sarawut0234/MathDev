# MathDev — เครื่องมือแปลงและคำนวณเลขฐาน

เว็บแอปภาษาไทยสำหรับแปลงและคำนวณเลขฐาน 2–36 พร้อมสไลด์บทเรียนและแบบฝึกหัด ใช้ Node.js ล้วน ไม่มี dependency ภายนอก

## ฟีเจอร์

### 1. แปลงฐาน
- แปลงจำนวนเต็มระหว่างฐาน 2 ถึง 36 (รวมฐานกำหนดเอง)
- รองรับค่าติดลบ เครื่องหมาย `+` และตัวอักษรพิมพ์เล็ก/ใหญ่
- ใช้ `BigInt` จึงรองรับตัวเลขขนาดใหญ่มากโดยไม่สูญเสียความแม่นยำ
- แสดงวิธีคิดทีละขั้นตอน (กระจายค่าประจำตำแหน่ง → หารซ้ำ → อ่านเศษย้อนกลับ)
- ปุ่มสลับฐานต้นทาง/ปลายทาง และปุ่มคัดลอกผลลัพธ์

### 2. คำนวณ
- บวก ลบ คูณ หาร ในฐานเดียวกัน (2–36)
- บวก/ลบแสดงการคำนวณทีละหลักพร้อมตัวทดและตัวยืม
- หารแสดงทั้งผลหารและเศษ
- ตรวจสอบคำตอบด้วยการเทียบกับฐานสิบ

### 3. สไลด์บทเรียน
- **สไลด์จากไฟล์ PDF ทั้ง 3 บท ขึ้นเว็บครบ 119 สไลด์**
  - บทที่ 1 เลขฐานและระบบจำนวน (21 สไลด์)
  - บทที่ 2 ลอจิกเกตและพีชคณิตบูลีน (55 สไลด์)
  - บทที่ 3 แผนผังคาร์โนห์ K-map (43 สไลด์)
- **แท็บเลือกบท** ด้านบน กดสลับบทได้ทันที
- **ปุ่มลูกศรหน้า/หลัง** เลื่อนสไลด์ทีละหน้า และใช้แป้น `←` `→` ได้
- **แถบความคืบหน้า** บอกตำแหน่งสไลด์ปัจจุบัน
- **แถบภาพย่อ (thumbnail)** เลื่อนแนวนอน กดเลือกสไลด์ที่ต้องการได้โดยตรง
- **กดที่ภาพสไลด์เพื่อเปิดดูเต็มหน้าจอ** (lightbox) พร้อมปุ่มเลื่อนหน้า แถบเลือกบท แถบภาพย่อ และตัวนับสไลด์
  - ใช้แป้น `←` `→` เลื่อนสไลด์ และ `Esc` ปิดได้ทันที
  - ปิดแล้วตำแหน่งสไลด์ในแท็บหลักจะตรงกับหน้าที่ดูอยู่ในหน้าต่างเต็มจอ
- ปุ่ม "แบบฝึกหัด" ท้ายแท็บสลับไปฝึกโจทย์ที่ดึงเนื้อหาจากสไลด์ได้ทันที

### 4. แบบฝึกหัด
- **ใส่ชื่อก่อนเริ่มฝึก** และจำชื่อไว้ในเครื่อง
- **กด "สุ่มโจทย์ 10 ข้อ" เพียงครั้งเดียว** เพื่อเริ่มชุด 10 ข้อ
- เมื่อเริ่มแล้ว **ซ่อนส่วนตั้งค่า** เหลือเพียงชื่อผู้ฝึกกับโจทย์ให้ทำ
- ปุ่ม **"ตั้งค่าใหม่"** เปิดส่วนตั้งค่ากลับมาเมื่อต้องการเปลี่ยนประเภทโจทย์
- **จับเวลาข้อละ 5 นาที** พร้อมแถบเวลาและแจ้งเตือนเมื่อใกล้หมด
- หมดเวลา = นับเป็นตอบผิด พร้อมแสดงเฉลยและวิธีคิด
- **ตอบถูก → ปุ่ม "ข้อถัดไป" ปรากฏทันที** ไม่ต้องรอเวลาครบ
- **ตอบผิด → ปุ่ม "ข้ามข้อนี้" ปรากฏขึ้น** กดเพื่อไปข้อถัดไป
- **ข้อที่ข้ามจะถูกเก็บไว้ แล้ววนกลับมาให้ทำใหม่** (สูงสุด 3 รอบ)
- **ทำครบทุกข้อแล้วแสดงสรุป**: ตอบถูก · ตอบผิด · เวลารวม · เวลาเฉลี่ยต่อข้อ
- แถบความคืบหน้าของชุด แสดงจำนวนข้อที่ทำแล้วจาก 10
- **หมวดโจทย์ 4 แบบ** เลือกได้ว่าอยากฝึกเรื่องอะไร
  - **เลขฐาน** (บทที่ 1): แปลงฐาน · บวก · ลบ · คูณ · หาร · **คอมพลีเมนต์ (1’s/2’s)** · อิสระ
  - **ลอจิกเกต** (บทที่ 2): หาค่าเอาต์พุตเกต · ตารางความจริง · De Morgan · Minterm/Maxterm · อิสระ
  - **K-map** (บทที่ 3): จัดกลุ่ม 1 · ลดรูปสมการ · อ่านช่อง K-map · อิสระ
  - **รวมทุกบท**: สุ่มคละจากสไลด์ทั้ง 3 บท
- เลือกฐาน: 2, 8, 10, 16 หรือ **คละฐาน** (หมวดเลขฐาน)
- เลือกระดับความยาก: ง่าย · ปานกลาง · ยาก (หมวดสไลด์ปรับจำนวนตัวแปร 2/3/4 ตัว)
- **โจทย์ทุกข้ออ้างอิงเนื้อหาในสไลด์** พร้อมช่อง "ดูสไลด์" บอกว่าอยู่บทไหน หัวข้ออะไร
- แสดงรายละเอียดโจทย์ทุกข้อ: ฐานที่ใช้ ชุดตัวเลข จำนวนหลัก ค่าประจำตำแหน่ง และวิธีทำ
- โจทย์ลอจิกแสดง **ตารางความจริง** และโจทย์ K-map แสดง **ตาราง K-map** ให้ดูประกอบ
- ตรวจคำตอบทันที แสดงเฉลยและวิธีคิดทีละขั้นตอน
- นับคะแนน ตอบถูก / ตอบผิด / ตอบถูกติดกัน

### 5. จัดอันดับ
- **โพเดียม 3 อันดับแรก** เรียงตามความสูงแบบโพเดียมจริง (อันดับ 1 อยู่กลางและสูงที่สุด) พร้อมอักษรย่อชื่อ คะแนน และเวลาเฉลี่ย
- **อันดับ 1 มีเอฟเฟกต์พิเศษ**: การ์ดไล่เฉดทองเรืองแสงเป็นจังหวะ, แสงกวาดผ่านการ์ด, รัศมีหมุนช้า ๆ ด้านหลัง, ประกายดาวกระพริบเป็นจุด ๆ และมงกุฎลอยเหนือการ์ด
- เอฟเฟกต์หยุดอัตโนมัติเมื่อระบบตั้งค่า "ลดการเคลื่อนไหว" (`prefers-reduced-motion`)
- ตาราง 10 อันดับแรก: อันดับ · ชื่อ · ตอบถูก · ตอบผิด · เวลาเฉลี่ย
- เรียงตามคะแนนที่ตอบถูก แล้วใช้เวลาเฉลี่ยเป็นตัวตัดสิน
- บันทึกคะแนนอัตโนมัติเมื่อทำชุดจบ ออกจากแท็บแบบฝึกหัด หรือเปลี่ยนชื่อ
- เก็บข้อมูลใน `localStorage` ของเบราว์เซอร์

## การใช้งาน

```bash
npm start
```

เปิด http://localhost:3000

เปลี่ยนพอร์ตได้ด้วยตัวแปรสภาพแวดล้อม:

```bash
PORT=3100 npm start
```

```
.
├── server.js          # เซิร์ฟเวอร์ HTTP ของ Node.js (เสิร์ฟไฟล์ static)
├── package.json
└── public/
    ├── index.html     # โครงหน้าเว็บ 5 แท็บ
    ├── style.css      # ธีมและ responsive (breakpoint 640 / 370 / 300px)
    ├── app.js         # ตรรกะการแปลง คำนวณ สไลด์ แบบฝึกหัด และจัดอันดับ
    ├── slides-data.js # สารบัญสไลด์ทั้ง 3 บท (สร้างจากไฟล์ PDF)
    └── slides/        # ภาพสไลด์ที่ render จาก PDF
        ├── ch1/       # บทที่ 1 · 21 สไลด์
        ├── ch2/       # บทที่ 2 · 55 สไลด์
        └── ch3/       # บทที่ 3 · 43 สไลด์
```

## UI/UX

- ดีไซน์สะอาด โทนม่วง-ขาว ฟอนต์ IBM Plex Sans Thai + Inter
- **การ์ดหลักและวิธีคิดอยู่ในกริดเดียวกัน** ระยะห่างสม่ำเสมอ ไม่มี margin ซ้อนกัน
- **แท็บบนมือถือเป็นแบบติดขอบ (sticky)** เลื่อนดูโจทย์ยาว ๆ แล้วสลับแท็บได้ทันที
- **มือถือ**: ระยะขอบ 14px, hero กระชับ, การ์ด padding 19/16px, ปุ่มเต็มความกว้าง
- **เดสก์ท็อป**: กว้างสูงสุด 860px, hero ใหญ่ขึ้น, การ์ด padding 27/30px
- รองรับหน้าจอ 240px ถึงเดสก์ท็อป (ทดสอบ 15 ขนาดจอ ไม่มี overflow)
- ช่องกรอกใช้ฟอนต์ 16px บนมือถือเพื่อป้องกัน iOS Safari ซูมหน้าจอ
- ใช้ ARIA roles/labels และ `aria-live` สำหรับผลลัพธ์
- ปุ่มและช่องกรอกมีขนาดแตะเหมาะกับมือถือ
- เคารพ `prefers-reduced-motion` (ปิดอนิเมชันโพเดียมและหน้าต่างสไลด์เต็มจอ)
- **แท็บสไลด์**: ภาพสไลด์ย่อตามความกว้างการ์ดด้วย `minmax(0, 1fr)` จึงไม่ล้นจอบนมือถือ
- **แถบภาพย่อ** เลื่อนแนวนอนได้ และเลื่อนตามสไลด์ที่เลือกอัตโนมัติ
- **หน้าต่างสไลด์เต็มจอ**: ใช้ `role="dialog"` + `aria-modal`, ล็อกโฟกัสด้วย `Tab`, ปิดด้วย `Esc` หรือคลิกฉากหลัง และคืนโฟกัสกลับปุ่มเดิม
- **โพเดียม**: ใช้ `grid` 3 คอลัมน์ ปรับขนาดการ์ดและระยะห่างตามเบรกพอยต์ จึงไม่ล้นจอตั้งแต่ 240px ขึ้นไป

## เทคโนโลยี

- Node.js (ไม่มี dependency ภายนอก)
- HTML/CSS/JavaScript แบบ vanilla
- `BigInt` สำหรับการคำนวณเลขฐานขนาดใหญ่
- ภาพสไลด์ render จาก PDF ด้วย PyMuPDF (ใช้เฉพาะตอนเตรียมไฟล์ ไม่ใช่ตอนรันเว็บ)
